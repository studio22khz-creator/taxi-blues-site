# TAXI BLUES — MP3 альбома «Овцы Христа»

Папка для 12 публичных MP3-файлов. Названия файлов латиницей, порядок альбома сохраняется.

**Для загрузки через браузер:** откройте эту папку GitHub, выберите **Add file → Upload files** и перетащите сюда 12 MP3 из архива `TAXI_BLUES_MP3_для_сайта.zip` (архив сначала распаковать). Нажмите **Commit changes**.

После загрузки файлы будут доступны по адресам:

`/assets/audio/01-tak-budet-luchshe.mp3` ... `/assets/audio/12-fudziyama-bonus.mp3`

Важно: на GitHub загружаются **MP3**, а не ZIP. Все треки из пользовательского архива 320 кбит/с, каждый меньше 25 МиБ. GitHub-репозиторий публичный, соответственно MP3 доступны слушателям и для скачивания.

Трек-лист сайта хранится в `content/tracks.json`. Не изменяйте его автоматически до появления файлов на сервере — иначе кнопки Play окажутся нерабочими.
